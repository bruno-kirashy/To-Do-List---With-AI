## 🧭 Visão geral

Este projeto é uma aplicação web de lista de tarefas pensada para ajudar no controle do dia a dia, com foco em simplicidade, organização e produtividade. A interface foi desenvolvida para permitir que o usuário registre atividades, marque conclusões, acompanhe o progresso e mantenha sua rotina mais clara e eficiente.

Além da funcionalidade principal de gerenciamento de tarefas, o projeto inclui recursos como:

- busca rápida por tarefas
- filtros por status
- paginação da lista
- notificações de ações importantes
- dashboard de progresso
- personalização visual por tema
- informações e guia de uso

## 🚀 Tecnologias utilizadas

- 🇧🇷 HTML5
- 🇧🇷 CSS3
- 🇧🇷 JavaScript

## ✨ Funcionalidades

- Adicionar novas tarefas pelo campo principal
- Marcar tarefas como concluídas
- Excluir tarefas da lista
- Buscar tarefas por nome
- Mostrar ou ocultar tarefas concluídas
- Visualizar progresso geral da rotina
- Receber notificações sobre conquistas e exclusões
- Alternar entre temas visuais
- Iniciar no modo escuro e alternar a aparência sem perder a paleta selecionada
- Navegar com uma interface moderna e intuitiva

## ▶️ Como executar localmente

1. Clone o repositório:

```bash
git clone https://github.com/seu-usuario/to-do-list-with-ai.git
```

2. Acesse a pasta do projeto:

```bash
cd to-do-list-with-ai
```

3. Abra o arquivo `index.html` no navegador.

Você também pode usar um servidor local simples, como:

```bash
python -m http.server 8000
```

Em seguida, acesse:

```text
http://localhost:8000
```
